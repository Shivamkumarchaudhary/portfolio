DevOps Architecture

Jenkins & Maven CI/CD Pipeline

Continuous Integration and Continuous Deployment flow: Git SCM to Jenkins Server, Maven build & testing, and GitHub Pages live hosting.

1

1. Git Commit & Push

Developers push code to the main branch on GitHub.

2

2. Jenkins Trigger

Jenkins polls SCM / Webhook and triggers the automated Jenkinsfile pipeline.

3

3. Maven Compile & Test

Maven executes mvn clean test to run automated JUnit verification test suites.

4

4. Maven Package

Maven runs mvn package to assemble the validated distribution artifact.

5

5. GitHub Pages Live

Validated release is deployed live on global Fastly CDN with SSL/HTTPS.
